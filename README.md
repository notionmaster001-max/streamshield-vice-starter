## 💻 How to Run in OBS Studio

1. In OBS Studio, click **Docks** → **Custom Browser Docks...**
2. Name it `StreamShield Soundboard`.
3. In URL, enter the local path to `soundboard.html`.
4. Click **Apply** and snap the dock next to your audio mixer!
